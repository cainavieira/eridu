```markdown
# Casos de Uso

## Admin
- Cria usuário
- Edita usuário
- Desativa usuário (exclusão evitada)
- Cria e edita produtos
- Vê logs do sistema
- Emite e acessa todos os relatórios

## Gerente
- Cria e edita produtos
- Define política de desconto (percentual máximo permitido)
- Aprova ou rejeita entrada de produtos no estoque
- Aprova ou rejeita movimentação de perda (produto vencido, quebrado)
- Cancela venda
- Emite e acessa relatórios de venda e estoque
- Acessa movimentações de cada caixa
- Visualiza fechamento de caixa

## Operador 
- Registra venda
- Adiciona e cancela item da venda
- Finaliza venda 
- Aplica desconto dentro do limite definido pelo Gerente
- Registra entrada de produtos no estoque 
- Registra perda de produto 
- Consulta estoque
- Fecha o próprio caixa ao encerrar turno
```
