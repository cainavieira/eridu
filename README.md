# 📌 Descrição

Sistema de gestão de estoque e vendas desenvolvido do zero como projeto de aprendizado em engenharia de software.

Este repositório documenta todo o processo de criação, desde as decisões de arquitetura até a implementação, com o objetivo de aplicar e demonstrar conhecimentos reais de desenvolvimento de software.
